Technical explanation
The server uses HMAC-SHA256 with a secret key that is never sent to the client. When the cookie payload is modified (e.g. changing user → admin), the HMAC tag becomes invalid. The server recomputes the expected MAC and uses hmac.compare_digest() to prevent timing attacks.
