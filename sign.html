Key Substitution Attack
Attacker forges a valid (m, sig) pair

The attacker picks an arbitrary signature s', computes m' = VERIFY(pk, s') with a newly generated key pair, then presents (pk', m', s') — verification passes because the relationship holds.

💀
Message/Key Substitution Attack
Forge (m', s) that passes verification

Given a valid (m, s), the attacker creates a new key pair pk' such that VERIFY(pk', m', s) = True for a different message m' — reusing the same signature with a crafted key.
